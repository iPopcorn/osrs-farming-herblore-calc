# OSRS Farming + Herblore Calculator
A calculator to find the most profitable herbs to grow.

Depends on .NET 10

## Run the project
1. clone the repo
2. cd into the cloned repo
3. run `dotnet restore`
4. run `dotnet run .`

## Run tests
1. clone the repo
2. cd into the cloned repo
3. cd into 'Calastone.Tests'
4. run `dotnet restore .`
5. run `dotnet test .`
